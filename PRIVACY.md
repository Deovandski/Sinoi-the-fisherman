# Privacy

Sinoi the Fisherman collects no personal data. There are no accounts, no cookies, no analytics, no ads and no tracking, in the app or on the website.

## The game (Android app and browser version)

- Your save is stored only on your device: in the app's private storage on Android, or in the website's browser storage (IndexedDB) on the web.
- Nothing is sent to us or anyone else. The game works offline.
- **Installed web app (PWA):** if you install the browser version or play it once, your browser keeps a copy of the game's files (the engine, game data, icons and an offline page, about 40 MB) so it can start with no signal. These files are stored only on your device, are never sent anywhere, and contain no personal data. The app only checks the website for a newer version of those files. Uninstalling the app or clearing this site's data removes them, along with the browser save.
- When you **export** a save, the game writes a JSON file where you choose (or to your downloads, or to your clipboard). When you **import** one, it reads only the file you pick.
- The Android app asks for no permissions.
- Links to Amazon and GitHub open in your browser; those sites have their own privacy policies.

## The website

The website at https://deovandski.github.io/Sinoi-the-fisherman/ is hosted on GitHub Pages, so [GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) sees your IP address when it sends you the pages. The site sets no cookies and runs no analytics.

**Languages.** The site opens in your browser's language when a translation is ready. If you pick a language in Settings, your browser remembers that choice on your device (local storage). It's never sent anywhere; clearing this site's data forgets it.

**Stats for nerds.** The debug page (Settings › DEBUG, `/debug/`) shows what your browser tells the page about itself: browser and device, screen, storage use, connection, page timings. It reads this only to show it to you on that page. Nothing is saved and nothing is sent anywhere; the page only asks this website for its build file (`stats.json`) and times three small requests to it.

## Google Play

If you install the app from Google Play, Google handles the download and may collect data under its own policies. The app itself adds nothing.
